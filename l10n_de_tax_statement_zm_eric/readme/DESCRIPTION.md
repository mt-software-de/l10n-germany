This module sends the *Zusammenfassende Meldung* (ZM) of the German VAT
Statement to the Bundeszentralamt für Steuern (BZSt) with ERiC, the
library of the tax administration. It glues *German VAT Statement
Extension* and *German VAT Statement ERiC* and is installed with both of
them.

It sends the ZM as the data type `ZMDO` with the certificate of Mein
ELSTER of the company, a BZSt-Nummer isn't needed.
