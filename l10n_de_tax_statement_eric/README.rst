This module sends the German VAT Statement (Umsatzsteuer-Voranmeldung)
of *l10n_de_tax_statement* to ELSTER with ERiC, the ELSTER Rich Client
library of the tax administration, instead of the upload of the XML
export in Mein ELSTER.

It validates the statement with ERiC and sends it on its approval with
the ELSTER certificate of the company and posts the transfer ticket and
the transmission protocol of ELSTER in the chatter.

ERiC isn't part of this module: its license doesn't allow to pass it on,
see *Installation*.

Installation
============

ERiC is a native library of the tax administration. Its license only
grants the use to the software manufacturer who downloaded it and
doesn't allow to pass it on, so neither this module nor its repository
contain it. Every operator gets it from ELSTER:

1. Register as software developer in the ELSTER developer area
   (https://www.elster.de/elsterweb/entwickler) and apply for a
   HerstellerID. ELSTER requires it in every transmission, enter it in
   Invoicing > Configuration > Settings > ELSTER.

2. Download the ERiC package for the platform of the Odoo server, e.g.
   ``ERiC-44.3.6.0-Linux-x86_64.jar``, from the download area for
   developers and accept its license. This module needs ERiC 44 or
   newer, on Linux with glibc 2.28 or newer. The version must support
   the Datenartversion of the statement, e.g. ``UStVA_2026``, see
   *Datenartversionmatrix.ods* of the ERiC documentation.

3. Extract it on the Odoo server, the package is a zip archive:
   ``unzip ERiC-44.3.6.0-Linux-x86_64.jar -d /opt``. Keep the library
   and its ``plugins`` directory together, ERiC searches its plugins
   next to ``libericapi.so``.

4. Point the Odoo server to the library in its configuration file:

   .. code:: ini

      [options]
      l10n_de_eric_library = /opt/ERiC-44.3.6.0/Linux-x86_64/lib/libericapi.so
      ; optional, the directory of eric.log, by default the temporary directory
      l10n_de_eric_log_path = /var/log/odoo/eric

   The environment variables ``L10N_DE_ERIC_LIBRARY`` and
   ``L10N_DE_ERIC_LOG_PATH`` work as well. The path is a server setting
   on purpose: the library runs inside the Odoo process, so it can't be
   set from the database.

5. Restart Odoo and install this module.

ELSTER publishes new ERiC versions regularly and the license requires to
use a current one: replace the library and update the path when a new
version is out.

Configuration
=============

In Invoicing > Configuration > Settings > ELSTER:

- **ELSTER HerstellerID**: the HerstellerID of the installation, see
  *Installation*.
- **ELSTER Test Transmission**: send the statements with the Testmerker
  700000004. ELSTER deletes them right after their receipt, they aren't
  declared and the statement isn't marked as sent. Use it to test the
  installation and the certificate.
- **Store the ELSTER Certificate**: by default the approval of a
  statement asks for the certificate file (``.pfx``) of Mein ELSTER and
  its PIN, and removes them from the database right after the
  transmission. With this option the file and its PIN are kept on the
  company and the approval sends the statement right away. Only
  administrators can read or replace them. Confirm the privacy notice of
  the tax administration there as well: the license of ERiC requires it
  before a transmission, the approval asks for the certificate until it
  is confirmed. Removing the option deletes the stored file and PIN.

Whoever has the certificate file and its PIN can send declarations in
the name of the company: keep the option off if the database, its
backups or its administrators shouldn't have them.

Only users of the group *Billing Administrator* (Adviser) can send a
statement.

Usage
=====

1. Create the statement and check its lines as described in *German VAT
   Statement*.
2. Press *Approve*: with this module the approval sends the statement to
   ELSTER. ERiC validates it against the rules of ELSTER first, errors
   stop the approval before anything is sent. With the certificate and
   its PIN stored on the company it sends it right away. Otherwise it
   asks for them: upload the certificate file of Mein ELSTER, enter its
   PIN, read the privacy notice of the tax administration and press
   *Send*, which approves the statement with them. Without ERiC
   configured on the server, *Approve* attaches the XML for the upload
   in Mein ELSTER like without this module.
3. ELSTER returns a transfer ticket and the transmission protocol: the
   statement is *Approved* and its message in the chatter has the
   ticket, the notes of ERiC and ELSTER and the protocol. Errors of ERiC
   or ELSTER are shown and the statement stays a draft. A test
   transmission leaves it a draft as well.

Known issues / Roadmap
======================

- Use the multithreading API of ERiC, the singlethreading API lets only
  one transmission per Odoo process run at a time.
- Support the other certificates of ELSTER, e.g. the signature card or
  the identity card (nPA).
- Show the privacy information of the tax administration on Articles 12
  to 14 GDPR, which the license of ERiC requires besides the privacy
  notice.
